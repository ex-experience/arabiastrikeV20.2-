# Mobile / GitHub Pages Deployment

1. Keep `index.html` in the repository root.
2. Enable GitHub Pages from `main` and `/(root)`.
3. Open the Pages URL on the phone.
4. The hero loading screen appears immediately.
5. Wait for `V20.3 READY`.
6. STORY and HOW TO PLAY are available before starting.
7. Press START MISSION.
8. Portrait controls use two independent non-overlapping grids.
9. Rotate the phone physically; the page switches automatically to Landscape.

`visualViewport` and safe-area insets keep the controls within the usable
Safari/Chrome viewport.
